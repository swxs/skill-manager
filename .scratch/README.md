# .scratch 临时工作区索引

本目录是**跨会话临时工作区**，归档按**产出它的真实会话**分目录存放。
**只往自己的会话目录写**。`.scratch/` 下每个会话一个目录，不要把自己的产物塞进别人的目录，也不要把别人的遗留产物混进自己的目录——按真实来源归档

`.gitignore` 中以 `.scratch/*` 忽略本目录**全部内容**，仅 `!.scratch/README.md` 例外：即本文件（描述 `.scratch` 怎么用）**进版本库**，其余一切（含 `资产索引.md`）**均为本地产物，不进版本库**。

## 目录约定

- **每个会话一个目录**：`.scratch/<会话目录名>/`
  - 普通会话用**裸 uuid**（DSH 内部目录名是 `session-<uuid>`，去掉 `session-` 前缀）。裸 uuid 与
    `~/.dsh/sessions/--D-codehouse-obsidian--/session-<uuid>/session.jsonl.zstd` 一一对应，便于回溯会话原文
  - Telegram 会话没有 uuid，且原始 id 形如 `telegram:2088674480:1786702820066`（含 `:`，Windows 非法），
    沿用 DSH 的转义目录名，如 `telegram~003A2088674480~003A1786702820066`
- **子目录按类型固定**：

| 子目录     | 内容                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `scripts/` | 脚本（`.py` `.mjs` `.cjs` `.ps1` `.ts` …）                                                                                                       |
| `data/`    | 数据与文档产物（`.json` `.geojson` `.zip` `.txt` `.log` `.md` `.bak` …）                                                                         |
| `images/`  | 图片产物。**保留原图集子目录名**——同一编号在多套图集里重名（如 `115.webp` 同时存在于 `before-apply3/`、`originals/`、`recrop/`），平铺会互相覆盖 |
| `repos/`   | 目录型资产（git 工作副本、node 包、npm 缓存）                                                                                                    |
| `trash/`   | 可重建的缓存与空目录（不删除，仅归档）                                                                                                           |

根目录只保留
- 索引 `README.md`、`资产索引.md`
- `.dsh-write-probe`。最后一个是 DSH 的写权限探针（内容 `ok`）
