# .scratch 临时工作区索引

覆盖所有其他指令规定路径的规则, **所有临时内容只往目录约定的会话目录写**。

## 目录约定

示例:

- 形如 `session-<uuid>` 的会话目录名为去除 `session-` 后的 `uuid`
  如: `6af14231-b467-4a60-a9ff-d9bb43d04e30`
- 形如 `telegram:2088674480:1786702820066`沿用 DSH 的转义目录名
  如: `telegram~003A2088674480~003A1786702820066`

- **子目录按类型固定**：

| 子目录     | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| `scripts/` | 脚本（`.py` `.mjs` `.cjs` `.ps1` `.ts` …）                               |
| `data/`    | 数据与文档产物（`.json` `.geojson` `.zip` `.txt` `.log` `.md` `.bak` …） |
| `images/`  | 图片产物。                                                               |
| `repos/`   | 目录型资产（git 工作副本、node 包、npm 缓存）                            |
| `trash/`   | 可重建的缓存与空目录（不删除，仅归档）                                   |
| `xxx/`     | 其他指令规定的文件夹名, 例如: `translate`, `issues`, `research` `        |

- 根目录只保留本索引 `README.md`、`资产索引.md`。

## 跨会话长期可用资产索引

资产明细见 `.scratch/资产索引.md`，添加资产需要用户明确同意。
